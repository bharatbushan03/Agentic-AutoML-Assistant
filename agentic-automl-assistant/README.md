# Agentic AutoML Assistant

A Streamlit web app that lets you upload a CSV dataset and automatically train baseline machine learning models.

## Features
- CSV upload and preview
- Quick dataset summary
- Automatic task type inference
- Baseline model training and evaluation
- Model and report export

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
